# Switchboard

A polyglot plugin runtime library providing host-owned, deterministic extensibility.

## Packages

| Package | Language | Description |
|---------|----------|-------------|
| [`switchboard-python`](packages/switchboard-python/) | Python | Python plugin runtime (`pip install switchboard`) |
| `switchboard-typescript` | TypeScript | TypeScript plugin runtime (`@switchboard/core`) — planned |
